# Saborê — React Native

Projeto didático de um aplicativo mobile de compartilhamento de receitas.

## Como rodar

1. Extraia a pasta.
2. Abra a pasta no VS Code.
3. Abra o terminal nessa pasta.
4. Rode:

```bash
npm install
npx expo start
```

5. No celular, abra o **Expo Go** e escaneie o QR Code.
6. Para rodar no navegador:

```bash
npm run web
```

## O que já funciona

- Home
- Explorar com busca e filtros
- Cards reutilizáveis
- Detalhes da receita
- Favoritos
- Criar receita
- Perfil
- Configurações
- Estados vazios
- Interações e alertas
- Dados locais de exemplo

## Próximas etapas para as aulas

Este projeto foi pensado para crescer durante as aulas. Depois você pode substituir os dados locais por:

- API externa
- Firebase
- autenticação
- armazenamento de imagens
- sincronização offline
- notificações
- acessibilidade mais avançada
- monitoramento e logs

As imagens das receitas são carregadas por URLs externas, então é necessário ter internet para visualizá-las.
